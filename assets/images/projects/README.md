# Project screenshots

Each project has its **own folder**. Number the files. You can add more than three.

- **`1.jpg`** = thumbnail on the project card (and first slide in details)
- **`2.jpg`, `3.jpg`, `4.jpg`…** = extra shots in the details gallery (arrows, thumbnails, left/right keys)

Also accepted: `.jpeg`, `.png`, `.webp`. Up to **12** images (`1`–`12`).
